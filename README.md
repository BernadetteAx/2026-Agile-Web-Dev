**Description**
NAME is a web-based Hangman game that allows users to play solo or interact with other players. Users can create accounts, play games, track scores, and view leaderboards. The application is designed to be engaging, intuitive, and interactive.

**Features**
•	User authentication (signup/login/logout)
•	Single-player Hangman gameplay
•	Score tracking and persistence
•	Leaderboard system
•	User-created word challenges
•	Game history tracking
